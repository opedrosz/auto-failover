# Agentes

Papeis: Planejador, Desenvolvedor, Revisor, Testador, Supervisor deterministico.
Nao exigir 5 modelos diferentes para tarefas simples.
Agente nao pode ampliar suas proprias permissoes.

## Execução local V1.0.6

Use uma base dedicada para a demo e mantenha os exemplos sintéticos. Os comandos do supervisor devem vir de código local confiável. Execute `python cli.py test` antes de publicar mudanças.
